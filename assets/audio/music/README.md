# Original music cues

These four instrumental synth loops were composed procedurally for IRON FRONT.
They contain no sampled recordings or third-party melodies. Regenerate with:

```sh
python3 tools/generate_music.py
```

- Coastal Assault: 132 BPM, ascending minor ostinato.
- Dust Convoy: 116 BPM, semitone motif.
- Foundry Pulse: 144 BPM, repeating low-register pattern.
- Boss Overdrive: 156 BPM, rapid octave motif.

The Godot audio manager enables sample-accurate looping on cached stream copies.
