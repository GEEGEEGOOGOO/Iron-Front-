# Graphics upgrade asset prompts

Generated with the built-in image_gen tool using the imagegen skill. Transparent background requested for each image.

These PNG sheets are visual references and source art, not rigged 3D models or UV-ready material maps. Integration now uses these references for procedural soldier, weapon, scout, siege and sentry models. The projectile atlas is consumed directly by FxAtlas for combat VFX. Use the soldier, weapon and tank sheets to guide the procedural Godot model pass. The projectile sheet requires extraction and in-game validation before sprite use; it is not a frame animation.
